# IP and Asset Provenance Policy

This project creates original IP inspired by the broad language of internet absurdist / brainrot culture. It does not clone protected characters.

## Do not ship

- Existing named brainrot/meme characters reproduced recognizably.
- Celebrity, streamer or influencer likeness/voice without documented permission.
- Brand logos, branded packaging, distinctive trademark use or copyrighted franchise characters.
- Scraped images, Pinterest/TikTok/Google image assets, unlicensed stock, watermarked art.
- Commercial music or viral audio without a license allowing game distribution.
- AI generations that intentionally imitate a living artist or are prompted to recreate protected characters.

## Asset provenance

Every production asset must record:

- internal asset ID;
- source/provenance;
- rights/license basis;
- master dimensions;
- runtime dimensions;
- status;
- notes if AI-assisted and human-edited.

The runtime asset manifest is `public/assets/manifest.json`. Source-art records may be expanded later as the asset pipeline grows.

## Naming

Before final product/character names are used commercially, run basic trademark/confusion checks in relevant markets. Repository codenames are not assumed to be cleared brands.
