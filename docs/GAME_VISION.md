# Game Vision

## Working title

Brainrot Merge Boss — repository codename only. Final market-facing name will be selected after creative testing and trademark checks.

## One-line pitch

Merge absurd collectible cartoon creatures, build a synergistic squad, crush oversized bosses, steal/mutate rewards, and grow a persistent collection.

## Audience

Primary: mobile-first casual players and younger meme-aware players who understand visual absurdity instantly.
Secondary: merge/idle/collection players who stay for progression even after a meme trend changes.

## Design pillars

1. **Instantly readable absurdity** — original creatures communicate personality in one glance.
2. **Satisfying merge** — every combination has anticipation, snap, transformation and reward.
3. **Boss spectacle** — bosses are oversized, animated, mechanically distinct and visually memorable.
4. **Collection desire** — rarity, mutations, silhouettes and reveal choreography create ownership value.
5. **Fast sessions, deep meta** — moment-to-moment play is simple; long-term progression offers depth.
6. **Trend-flexible original IP** — visual language can react to internet culture without copying protected characters.

## Core loop

Acquire -> Merge -> Build squad -> Fight -> Boss -> Choose/steal reward -> Upgrade collection -> Enter next encounter.

## Meta loop

Unlock species -> discover mutations -> improve persistent stats -> complete worlds -> daily boss/events -> prestige/seasonal goals.

## Monetization principles

- Rewarded first, interstitial second.
- Ads occur at logical breaks, not during active combat.
- No pay-to-remove-friction design that intentionally makes base play miserable.
- Purchases, if/when enabled, sell convenience/cosmetics/value bundles rather than required progress.
