# Skill: Art Direction

## Use when
Any task changes visible game art, scene composition, color/material treatment, backgrounds, characters, bosses, icons, key art, or visual hierarchy.

## Required references
Read `docs/ART_DIRECTION.md`, `docs/QUALITY_GATES.md`, and `docs/IP_POLICY.md`.

## Workflow
1. State the player-facing visual goal in one sentence.
2. Identify gameplay viewing size and device orientation before judging detail.
3. Preserve the established silhouette/material/lighting language.
4. Prefer one strong focal idea over many unrelated details.
5. Review final output at native scale and at small mobile gameplay scale.
6. Reject any asset with artifacts, illegible anatomy, accidental text, muddy edges, or style drift.
7. Register final runtime assets with provenance.

## Hard rules
- Never use emoji or debug primitives as final art.
- Never upscale a bad low-res image and call it high-res.
- Do not mix photoreal, flat vector, painterly, and 3D-render aesthetics without an explicit art-direction decision.
- Background contrast must preserve board/unit readability.
