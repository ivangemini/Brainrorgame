# Skill: Character & Boss Design

## Use when
Creating or revising creatures, bosses, mutations, skins, rarity variants, silhouettes, names, or visual concepts.

## Required references
Read `docs/ART_DIRECTION.md` and `docs/IP_POLICY.md`.

## Design recipe
For each character define:
- one-sentence visual joke/concept;
- silhouette primitive;
- dominant prop/material;
- face/personality read;
- gameplay role;
- rarity/mutation hooks;
- color/material notes;
- animation opportunities;
- IP-distance check from known memes/brands/people.

## Boss rules
- Boss silhouette must read materially larger and more threatening than normal units.
- Boss attacks need visible telegraph shapes that do not rely only on color.
- Each boss needs at least one signature motion and one signature defeat beat.
- Reused base rigs are allowed only when the silhouette and encounter identity remain distinct.

## Naming
Prefer original absurd names. Do not create names deliberately confusingly similar to well-known meme characters, brands, celebrities, or franchises.
