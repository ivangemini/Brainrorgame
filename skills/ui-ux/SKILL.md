# Skill: Game UI / UX

## Use when
Changing HUD, menus, collection, shop, onboarding, buttons, tooltips, modal flow, progression screens or responsive layout.

## Principles
- Game-first: UI frames the content rather than looking like a generic web dashboard.
- Primary action must be obvious without reading long copy.
- Touch targets should be generous and separated.
- Preserve safe areas and portrait/landscape constraints.
- Use icon + short label where comprehension benefits.
- Rarity and currency visuals must stay consistent across the entire game.
- Motion should clarify hierarchy and state change, not merely decorate.

## Visual bar
No default browser controls, unstyled HTML, generic gradient cards, emoji icons, random rounded rectangles, or mismatched icon sets in player-facing production UI.

## Validation sizes
At minimum review representative portrait mobile, tall mobile, tablet-ish, and desktop/landscape layouts for screens they support.
